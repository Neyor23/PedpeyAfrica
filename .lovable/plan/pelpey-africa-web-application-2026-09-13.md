# PelPey Africa Web Application

## Overview
Build a polished, single-page civic-development platform inspired by Civic Coded’s clarity and directness, with a distinct African visual identity. The experience will be responsive, accessible, animated with restraint, and fully usable in light and dark modes.

## What will be built
- A sticky top navigation with PelPey Africa branding, section links, theme control, and Sign In / Sign Up actions.
- A bold opening section containing the supplied title and subtitle, a prominent search experience, a stylized interactive Africa map, and the three requested key-question cards.
- A visual feature section blending sculptural African forms with contemporary AI and development imagery.
- An “Explore by Topics” section with the three requested topic cards and clear subtopics.
- Two interactive community areas:
  - “Lesson Capital” contribution box with validation and confirmation feedback.
  - “Question and Answers” box with question submission and sample community responses.
- A six-item article grid using the exact supplied titles, with clickable detail previews.
- A comprehensive footer with branding, quick links, explore links, and legal links.

## Visual direction
- Deep forest greens, warm gold/amber, dark navy, and clean neutral surfaces.
- Editorial typography, crisp civic-tech layouts, subtle geometric African patterning, and restrained borders/radii.
- Custom generated imagery for the sculpture/AI feature and article visuals, avoiding generic stock imagery.
- Smooth entrance, map, theme, and interaction transitions with reduced-motion support.

## Interaction and responsiveness
- Search filters and highlights matching topics/articles.
- Map regions and markers respond to hover/focus and reveal development themes.
- Navigation scrolls to relevant sections; mobile navigation collapses cleanly.
- Theme preference persists locally and respects the visitor’s system setting initially.
- Sign In / Sign Up open polished interface dialogs; no account storage or real authentication will be added.
- Community submissions work in the current visit only; no permanent storage will be added.

## Technical details
- Implement in the existing TanStack Start home page using React and Tailwind CSS v4.
- Define all visual values as semantic design tokens in the global stylesheet.
- Use accessible controls, keyboard states, semantic headings, descriptive image text, and route-specific metadata.
- Verify the finished experience at desktop and mobile sizes, including interactions and theme switching.
